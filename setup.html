eOffis – Einrichtung

Die Texte werden immer aus dem neuesten Stand geladen. Kopieren, in Supabase einfügen, fertig.

1. Datenbank

  1. Supabase → SQL Editor → New query.
  2. Einfügen und Run. Mehrfaches Ausführen ist unschädlich.

2. KI-Funktion

  1. Supabase → Edge Functions → bestehende KI-Funktion öffnen (oder Deploy a new function → Via Editor).
  2. Alles im Editor ersetzen, Deploy. „Verify JWT“ bleibt aus.

3. Server-Funktion „eoffis-api“

  1. Wie oben, Name eoffis-api, „Verify JWT“ aus.
  2. Secrets laut Anleitung in der Datei (oben im Text) anlegen.
